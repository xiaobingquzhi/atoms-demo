# DESIGN.md

## Direction & Layout
产品是一个「AI 任务智能体」工作台：输入目标 → AI 拆解为结构化任务卡片 → 逐条执行/生成测试用例。气质应是**冷静、克制、工程化**，像一块深色控制台，而不是彩色的待办玩具。第一屏视觉信号：顶部一条细长的目标输入条（命令行式），下面是任务卡片的单列纵向流。禁止五彩渐变、玻璃拟态、装饰性插画。

- 布局：单页，最大内容宽度 960px，左右 padding 桌面 32px / 移动 16px。区块间距 32px，卡片间距 12px。
- 焦点：目标输入区（大号 textarea + 主按钮），永远位于首屏顶部。
- 层级：输入区 → 操作条（生成测试用例 / 清空 / 设置）→ 任务列表 → 测试用例抽屉式展开在卡片内部。
- 断点：<640px 时按钮组换行占满宽度，卡片操作图标按钮保持 40px 触控区；≥640px 时按钮横排。
- Do：保持深色背景 + 单一青绿强调色；空状态给出明确指引。Don't：不要卡片左侧彩条、不要蓝紫渐变、不要居中英雄大图。

## Tokens
- 颜色：背景 `#0E1116`，卡片面 `#171B22`，次级面 `#1F242D`，边框 `#2A313C`，主文字 `#E6EAF0`，次文字 `#9AA4B2`，强调 `#4ADE9B`（仅用于主按钮、完成态、焦点环），危险 `#F87171`，警告 `#FBBF24`。
- 字体：`"IBM Plex Sans", system-ui, sans-serif`，代码/用例用 `"IBM Plex Mono", monospace`。H1 24px/700/1.3；卡片标题 16px/600/1.5；正文 14px/400/1.6；说明 12px/400/1.5。
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32。圆角：卡片 12px，按钮 8px，输入 10px，图标按钮 8px。
- 深度：以 1px `#2A313C` 边框划分层级，仅弹层使用 `0 8px 24px rgba(0,0,0,.45)`。不使用模糊玻璃效果。

## Shared Patterns & States
- 主按钮：强调底 `#4ADE9B` + 深色文字 `#0E1116`；次按钮：透明底 + 边框 + 主文字。禁用时 40% 透明并禁止指针。
- 任务卡片：面色卡片，含复选框、可编辑文本（contenteditable/inline input）、测试用例区、删除按钮。完成态文字灰化并加删除线。
- 加载态：按钮内联小圆点旋转 + 文案「生成中…」；错误态在顶部显示可关闭的红色提示条。
- 空状态：居中次文字「还没有任务，先描述你的目标」。
- 动效：150ms ease-out，仅用于悬停与展开；无入场动画，首屏内容直接可见。
- 可访问性：触控目标 ≥40px；焦点环 2px `#4ADE9B`；图标按钮有 aria-label。

## Media
纯操作型工具界面，不需要摄影或插画素材；图标使用内联 SVG。背景保持纯色，不使用抽象渐变图。
