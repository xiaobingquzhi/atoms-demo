# Atoms Demo（ROOT 笔试 · 测试岗）

## 这是什么
一个 AI 代码生成智能体网页：输入需求 → AI 生成可运行的 HTML 应用 → 右侧实时预览。
使用 ROOT 官方 Atoms 平台通过 vibe coding 构建，本人作为测试工程师负责需求定义、功能测试、缺陷记录与验收。

## 满足笔试要求
- [x] 真实交互：输入需求 → 生成代码 → 实时预览
- [x] 数据持久化：localStorage 保存历史记录，刷新不丢失
- [x] 扩展能力：一键生成测试用例 / 导出 HTML 文件
- [x] 可在线访问：见在线链接

## 如何使用
1. 打开在线链接
2. 右上角【API设置】填入你的 LLM API Key（只存在浏览器本地）
3. 左侧输入需求，点【生成应用】
4. 右侧查看预览，可复制代码 / 生成测试用例 / 导出 HTML

## 我的测试工作
- 手工测试用例：10条（覆盖正常/空输入/超长输入/刷新持久化/API错误/断网等）
- 缺陷记录：共发现 X 个 bug，已全部反馈 Atoms 修复
- 非功能：Chrome / Edge 兼容性验证通过

## 技术栈
HTML + TailwindCSS + 原生JS + LocalStorage + LLM API
